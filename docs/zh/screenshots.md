# 截图图库

[English](../screenshots.md) | **简体中文**

Figma 插件与 Cursor MCP 配置界面一览。图片地址均为 GitHub raw。

## 插件在 Figma Desktop 中打开

完整面板：**MCP Bridge 已连接**（绿色状态）、选区与功能模块。

![Figma Desktop 中的 Figma Agent Kit 插件](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/plugin-in-figma.png)

## 设置菜单

齿轮菜单：模型设置、提示词设置、检查更新、**中文 / English** 语言切换。

![插件设置菜单](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/plugin-settings-menu.png)

## 模型设置

OpenAI 兼容的 **API base URL**、模型名、API Key，以及 **测试连接**。

![模型设置对话框](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/plugin-model-settings.png)

## 导出切图

**导出切图** 标签：1× 预览、可编辑文件名、单张下载与 **ZIP** 打包（3× PNG）。

![导出切图模块](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/plugin-export-slices.png)

## 提示词设置

可编辑重命名 / 分组系统提示词（含 `{{candidates}}` 等占位符）。

![AI 提示词设置](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/plugin-prompt-settings.png)

## Mini 模式

紧凑窗口：仅桥状态 + 当前选区（使用标题栏最小化）。

![插件 Mini 模式](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/plugin-mini-mode.png)

## Cursor MCP 配置

`mcp.json` 中使用 `npx` 的示例（未锁定，npx 安装最新版）。

![Cursor mcp.json 配置](https://raw.githubusercontent.com/ChinaCarlos/figma-agent-kit/main/docs/images/cursor-mcp-config.png)

## Cursor MCP 工具列表
